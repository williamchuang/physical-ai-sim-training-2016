# `media/materials/` — Ogre materials for the track, cubes, coins and panels

`pai.material` defines every material the game uses:

| Material | |
|---|---|
| `Pai/Track` | the strip, with darker kerbs at the edges so the bot camera can see them |
| `Pai/Lit` | the lit base the cube and coin materials derive from |
| `Pai/Human`, `Pai/Neural`, `Pai/Scripted` | your cube, the bots, the obstacle cubes |
| `Pai/Coin` | the coins, bright and emissive so they stand out in a 20 x 20 grey image |
| `Pai/Sun` | the sky light marker |
| `Pai/HudPanel`, `Pai/ConsolePanel`, `Pai/MenuPanel` | backgrounds of the HUD, Lua console and menu |
